## ✨ 天道试炼塔自动挑战助手

### 功能特性
- ⚔️ **自动挑战**：自动循环挑战试炼塔，支持设置目标层数
- 🎯 **智能选天赋**：暴击优先排序，同类型词条自动选数值最大，支持四种策略
- 💎 **灵石刷新**：自动使用灵石刷新天赋池，优先获取高品质天赋
- 📊 **天赋追踪**：实时显示天赋加成效果（攻击/防御/生命/灵力/暴击等）
- 🧬 **天赋组合记录**：记录当前轮次获得的所有天赋及稀有度统计
- 🧘 **冥想控制**：根据开关状态智能暂停/恢复冥想，战斗中不触发冥想
- 🌓 **主题切换**：日间/夜间模式，保护视力
- 🔑 **盐值验证**：自动获取会话盐值，未登录时脚本不激活，避免无效请求
- ⏳ **API退避机制**：API请求失败时自动递增等待时间（5秒~60秒），恢复后自动重置
- ⌨️ **快捷键**：`Ctrl+T` 快速开始/停止
- 📱 **双端适配**：PC端浮动面板 + 移动端抽屉式面板
- 💾 **位置记忆**：面板和按钮位置自动保存

### 天赋选择逻辑

#### 同类型词条选最大（v4.3.2 新增）
当可选天赋中出现多个同类型词条时（如多个攻击类天赋），自动比较词条数值：
- 提取词条描述中的数值（如"攻击+15%" → 15）
- 选择数值最大的词条
- 数值相同时按稀有度选择（传说 > 稀有 > 普通）
- 日志标注 `📊 同类型X个Y词条，选最大`

#### 暴击未满时（<100%）
1. **特殊词条最优先**：不死 > 斩杀 ≈ 汲取 > 灵根共鸣
2. 暴击 > 攻击 > 生命 > 防御 > 灵力（同类型选最大）

#### 暴击已满时（≥100%）
1. 攻击 > 生命 > 防御 > 灵力（同类型选最大）
2. 无匹配则选默认第一个

### 天赋策略说明

| 策略 | 特点 |
|------|------|
| 综合平衡（暴击优先） | 优先暴击属性，兼顾各项数值 |
| 攻击优先 | 优先选择攻击类天赋 |
| 防御优先 | 优先选择防御/生命类天赋 |
| 传说品质优先 | 优先选择传说品质天赋 |

### 特殊词条识别
自动识别并优先选择以下特殊天赋：
- ✨ **不死**：首次HP归零恢复20%HP
- ⚔️ **斩杀**：敌人HP<20%伤害翻倍
- 🌀 **天道汲取**：击杀回复30%HP+30%MP
- 🌿 **灵根共鸣**：灵根战斗特效强化
- ⚡ **天怒**：攻击+30%

### 冥想机制说明（v4.3.2 优化）
- **勾选"自动冥想"**：战斗中暂停冥想，战斗结束后自动恢复
- **未勾选"自动冥想"**：启动挑战时暂停冥想，停止后不恢复
- 战斗中不触发冥想操作，避免影响战斗流程

### API退避机制说明
当脚本的API请求连续失败时，会自动进入退避状态：
- 第1次失败 → 等待 5 秒
- 第2次失败 → 等待 10 秒
- 第3次失败 → 等待 15 秒
- ...
- 最大等待上限 → 60 秒

一旦某次请求成功，退避计数器立即归零，恢复正常请求频率。

## ⚒️ 自动炼造助手

### 功能特性
- 🔥 **三模式支持**：炼丹、炼器、制符一键切换
- 📋 **智能配方选择**：自动加载可用配方，显示材料是否充足
- ⚡ **批量炼制**：自定义每次数量和循环次数，全自动生产
- 🛒 **材料补充**：材料不足时支持一键/自动购买材料（可预览费用）
- 📊 **进度追踪**：实时进度条 + 状态提示
- 📝 **完整日志**：炼制过程详细记录，支持清空
- 🌓 **自动主题**：跟随系统日间/夜间模式自动切换
- 💾 **完全记忆**：运行状态、配方选择、面板位置全部持久化
- 🔐 **API签名**：内置MD5签名算法，兼容游戏API安全验证
- 🚨 **登录检测**：Token过期自动跳转登录页

### 炼制模式

| 模式 | 说明 | 默认间隔 |
|------|------|----------|
| 炼丹 | 自动炼制丹药 | 5秒 |
| 炼器 | 自动锻造装备 | 7秒 |
| 制符 | 自动制作符箓 | 3秒 |

### 配方选择
- 自动显示当前模式所有可用配方
- 绿色标签 = 材料充足，红色标签 = 材料不足
- 材料不足时显示 **[+ 补充]** 按钮，支持预览费用

### 材料补充流程
1. 点击 **[+ 补充]** 按钮
2. 输入需要补充的份数
3. 系统自动预览总费用
4. 确认后自动购买材料
5. 材料补充成功后自动刷新配方列表

## 📥 安装方法

### 前提条件

#### 桌面端浏览器
安装浏览器扩展 **Tampermonkey** 或 **Violentmonkey**：
- [Chrome 版 Tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- [Firefox 版 Tampermonkey](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/)
- [Edge 版 Tampermonkey](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
- [Violentmonkey](https://violentmonkey.github.io/)

#### Via 浏览器（Android）
1. 下载安装 [Via 浏览器](https://viayoo.com/)
2. 打开 Via 浏览器，点击底部菜单 → **设置** → **脚本**
3. 开启 **脚本功能** 开关
4. 脚本功能已激活，可导入用户脚本

### 安装脚本

#### 方式一：直接安装（推荐）
点击下方链接自动安装：

- [安装 天道试炼塔自动挑战助手（Gitee）](https://raw.giteeusercontent.com/qiyes/ling-verse-script/raw/master/ling-trial-tower-assistant.js)
- [安装 天道试炼塔自动挑战助手（GitHub）](https://raw.githubusercontent.com/ming-a1/LingVerse-Script/refs/heads/main/ling-trial-tower-assistant.js)
- [安装 自动炼造助手](https://gh-proxy.org/https://raw.githubusercontent.com/ming-a1/LingVerse-Script/main/ling-craft.js)

#### 方式二：手动安装
1. 打开 Tampermonkey/Violentmonkey 管理面板
2. 点击 **创建新脚本**
3. 复制对应脚本文件内容并粘贴
4. 保存即可

#### 方式三：Via 浏览器安装
1. 打开 Via 浏览器，进入 **设置** → **脚本**
2. 点击右上角 **+** 号 → **从链接导入**
3. 粘贴脚本直链地址
4. 点击 **确定** 导入
5. 确保脚本开关已开启

> 💡 也可直接复制脚本全部代码，在 Via 脚本页面点击 **+** → **新建**，粘贴代码后保存。

## 🎮 使用方法

### 天道试炼塔自动挑战助手

1. 进入游戏后，打开 **天道试炼塔** 页面
2. 脚本会自动显示浮动按钮/面板
3. 配置策略和选项
4. 点击 **开始挑战** 或按 `Ctrl+T`

### 自动炼造助手

1. 进入游戏后，点击右下角浮动按钮 ⚒️ 打开面板
2. 选择炼制模式：**炼丹** / **炼器** / **制符**
3. 从配方列表中选择要炼制的物品（材料充足时可直接选择）
4. 配置炼制参数：
   - **每次数量**：单次炼制的成品数量（1-50）
   - **循环次数**：炼制轮数（1-999）
   - **间隔时间**：每轮之间的等待时间（毫秒）
   - **自动补材料**：开启后材料不足时自动购买
5. 点击 **开始炼制**，确认后自动执行
6. 可随时点击 **停止** 中断炼制
7. 点击面板标题栏按钮 **─** 可最小化为浮动按钮

## 💡 常见问题

<details>
<summary><strong>Q: 脚本没有生效？</strong></summary>

- 确保已正确安装 Tampermonkey 扩展 / Via 脚本功能已开启
- 检查脚本是否处于启用状态
- 确认页面地址匹配 `ling.muge.info`
- **试炼塔助手需登录游戏后才能激活**（需获取会话盐值）
- 尝试刷新页面
</details>

<details>
<summary><strong>Q: 自动炼造助手配方列表为空？</strong></summary>

- 确认已登录游戏
- 确认已学习对应模式的配方（炼丹需有丹方，炼器需有锻造配方等）
- 切换模式后稍等片刻，脚本会自动加载
</details>

<details>
<summary><strong>Q: 炼制时提示材料不足？</strong></summary>

- 开启 **自动补材料** 开关，脚本会在材料不足时询问是否自动购买
- 也可手动点击配方旁的 **[+ 补充]** 按钮预先购买材料
- 确保灵石充足
</details>

<details>
<summary><strong>Q: 自动挑战/炼制长时间无响应？</strong></summary>

- 检查网络连接是否正常
- API请求失败后会自动进入退避等待，请耐心等候
- 查看日志了解具体原因
</details>
