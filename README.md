# 灵界（LingVerse）游戏辅助脚本

适用于 [灵界](https://ling.muge.info/) 的 Tampermonkey 用户脚本集合，提升游戏体验。

## 📦 包含脚本

| 脚本 | 版本 | 功能 |
|------|------|------|
| **自动试炼塔 [X]** | v1.6.7 | 自动挑战试炼塔，智能选天赋，跟随页面主题 |
| **天道试炼塔自动挑战助手** | v4.3.2 | 自动挑战试炼塔，智能选择天赋 |
| **自动炼制** | v1.3.7 | 自动炼造 + 符篆批量使用 |

## ✨ 自动试炼塔 [X]（推荐）

> 新一代试炼塔助手，基于权重评分的智能天赋选择系统，自动跟随页面主题。

### 功能特性
- ⚔️ **自动挑战**：自动循环挑战试炼塔，支持设置目标层数和失败重试
- 🎯 **智能天赋选择**：基于权重评分的智能排序算法，特殊词条自动优先
- 🧠 **双策略模式**：默认配置 + 天赋权重自配（可自由调整每个词条的评分权重）
- 💎 **灵石刷新**：可选天赋分值过低时自动刷新，支持设置刷新次数上限
- 📊 **天赋面板**：展开/收起，显示攻击/血量/灵力/暴击等10项属性加成
- 🏷️ **天赋标签**：传说特殊词条和普通天赋分类展示
- 🧘 **冥想处理**：自动检测冥想状态，收功后等待3秒确保服务器同步
- 💡 **蓝色呼吸灯**：PC端收起标题栏后，运行中面板边框呈现蓝色呼吸动画
- 🌓 **跟随页面主题**：自动适配游戏页面的日间/夜间模式，无需手动切换
- ⚙️ **浏览器标题显示**：可自定义标题模板，实时显示当前挑战层数
- 📱 **屏幕常亮**：防止设备自动锁屏（需浏览器支持 Wake Lock API）
- 💻 **PC端标题栏收起**：点击箭头可折叠面板，节省屏幕空间
- 📲 **移动端悬浮球**：运行中悬浮球呈金色呼吸动画
- 🎨 **可拖动面板**：面板和悬浮球位置自由拖动，自动记忆
- 📝 **彩色日志**：info/warn/success/error/gold 五种日志级别

### 天赋策略说明

#### 默认配置策略
- **暴击未满（<100%）**：特殊词条 > 暴击(90) > 攻击(50) > 生命(40) > 防御(30) > 灵力(20) > 其他
- **暴击已满（≥100%）**：特殊词条 > 攻击(50) > 生命(40) > 防御(30) > 灵力(20) > 暴击(1) > 其他
- **特殊词条排序**：不死(100) > 斩杀(95) > 天怒(90) > 灵根共鸣(85) > 天道汲取(80)

#### 天赋权重自配
- 可独立调整 5 个传说特殊词条和 8 个普通词条的权重值
- 支持一键恢复默认权重

### v1.6.7 更新亮点
- 🌓 **主题系统重构**：移除独立主题切换按钮，改为自动跟随游戏页面主题
- ⏱️ **冥想收功优化**：等待时间从 1.5 秒延长至 3 秒，重试前增加 2 秒缓冲
- 🔧 **界面精简**：移除手动主题切换按钮，配置面板移除"跟随系统"选项
- 📌 **版本号显示**：面板标题栏显示当前版本号

## ✨ 天道试炼塔自动挑战助手

### 功能特性
- ⚔️ **自动挑战**：自动循环挑战试炼塔，支持设置目标层数
- 🎯 **智能选天赋**：暴击优先排序，同类型词条自动选数值最大，支持四种策略
- 💎 **灵石刷新**：自动使用灵石刷新天赋池
- 📊 **天赋追踪**：实时显示天赋加成效果
- 🧘 **冥想控制**：根据开关状态智能暂停/恢复冥想
- 🔑 **盐值验证**：未登录时脚本不激活
- ⏳ **API退避机制**：请求失败时递增等待（5~60秒）
- ⌨️ **快捷键**：`Ctrl+T` 快速开始/停止
- 📱 **双端适配**：PC端浮动面板 + 移动端抽屉式面板

## ⚒️ 自动炼制

### 功能特性

#### 炼造模块
- 🔥 **三模式支持**：炼丹、炼器、制符一键切换
- 📋 **智能配方选择**：自动加载可用配方
- ⚡ **批量炼制**：自定义每次数量和循环次数
- 🛒 **材料补充**：材料不足时自动静默购买

#### 符篆模块
- 📿 **符篆批量使用**：自动识别并批量使用符篆
- 🎯 **类型筛选**：全部/战斗/隐匿
- 🔄 **循环使用**：支持无限循环
- ⚠️ **安全检测**：陨落/遭遇妖兽时自动暂停

## 📥 安装方法

### 前提条件

#### 桌面端浏览器
安装浏览器扩展 **Tampermonkey** 或 **Violentmonkey**：
- [Chrome 版 Tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- [Firefox 版 Tampermonkey](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/)
- [Edge 版 Tampermonkey](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
- [Violentmonkey](https://violentmonkey.github.io/)

#### Via 浏览器（Android）
1. 下载安装 [Via 浏览器](https://viayoo.com/)
2. 打开 Via 浏览器，点击底部菜单 → **设置** → **脚本**
3. 开启 **脚本功能** 开关

### 安装脚本

#### 方式一：直接安装（推荐）

- [安装 自动试炼塔 [X]](https://v6.gh-proxy.org/https://raw.githubusercontent.com/ming-a1/LingVerse-Script/main/Auto-Trial-Tower-X.js)
- [安装 天道试炼塔自动挑战助手（Gitee）](https://raw.giteeusercontent.com/qiyes/ling-verse-script/raw/master/ling-trial-tower-assistant.js)
- [安装 天道试炼塔自动挑战助手（GitHub）](https://raw.githubusercontent.com/ming-a1/LingVerse-Script/refs/heads/main/ling-trial-tower-assistant.js)
- [安装 自动炼制](https://gh-proxy.org/https://raw.githubusercontent.com/ming-a1/LingVerse-Script/main/ling-craft.js)

#### 方式二：手动安装
1. 打开 Tampermonkey/Violentmonkey 管理面板
2. 点击 **创建新脚本**
3. 复制对应脚本文件内容并粘贴
4. 保存即可

#### 方式三：Via 浏览器安装
1. 打开 Via 浏览器，进入 **设置** → **脚本**
2. 点击右上角 **+** 号 → **从链接导入**
3. 粘贴脚本直链地址
4. 点击 **确定** 导入

## 🎮 使用方法

### 自动试炼塔 [X]

1. 进入游戏后，打开 **天道试炼塔** 页面
2. PC端面板自动显示在右侧，移动端点击悬浮球 ⚔️
3. 面板自动跟随游戏主题（日间/夜间）
4. 点击 ⚙ 配置按钮设置策略和选项
5. 点击 **开始试炼** 开始自动挑战
6. PC端可点击箭头 ▼ 收起面板（运行中显示蓝色呼吸灯）

### 自动炼制

1. 点击右下角浮动按钮 ⚒️ 打开面板
2. 在 **功能选择** 中切换 **炼造** / **符篆**
3. 选择模式/配方，配置参数，点击开始

## 💡 常见问题

<details>
<summary><strong>Q: 试炼塔 [X] 和旧版有什么区别？</strong></summary>

- **[X] 版** 基于权重评分系统，可自定义每个词条的分值
- 新增蓝色呼吸灯、屏幕常亮、标题显示层数等实用功能
- 自动跟随页面主题，无需手动切换
- 冥想收功等待 3 秒，状态同步更稳定
- **推荐新用户使用 [X] 版**
</details>

<details>
<summary><strong>Q: 如何切换主题？</strong></summary>

- v1.6.7 起主题自动跟随游戏页面设置
- 在游戏内切换日间/夜间模式后，面板会自动适配
</details>

<details>
<summary><strong>Q: 蓝色呼吸灯不显示？</strong></summary>

- 仅在 PC 端运行中且面板收起时显示
- 移动端运行中悬浮球会显示金色呼吸动画
</details>
