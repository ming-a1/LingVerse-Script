# 灵界（LingVerse）游戏辅助脚本

适用于 [灵界](https://ling.muge.info/) 的 Tampermonkey 用户脚本集合，提升游戏体验。

## 📦 包含脚本

| 脚本 | 版本 | 功能 |
|------|------|------|
| **自动试炼塔 [X]** | 最新 | 自动挑战试炼塔，智能选天赋，支持多策略 |
| **天道试炼塔自动挑战助手** | v4.3.2 | 自动挑战试炼塔，智能选择天赋 |
| **自动炼制** | v1.3.7 | 自动炼造 + 符篆批量使用 |

## ✨ 自动试炼塔 [X]（推荐）

> 新一代试炼塔助手，优化冥想收功等待时间，操作更稳定。

### 功能特性
- ⚔️ **自动挑战**：自动循环挑战试炼塔，支持设置目标层数
- 🎯 **智能选天赋**：暴击优先排序，同类型词条自动选数值最大
- 💎 **灵石刷新**：自动使用灵石刷新天赋池，优先获取高品质天赋
- 📊 **天赋追踪**：实时显示天赋加成效果（攻击/防御/生命/灵力/暴击等）
- 🧬 **天赋组合记录**：记录当前轮次获得的所有天赋及稀有度统计
- 🧘 **冥想控制优化**：收功等待时间延长至 1.5 秒，确保服务器状态同步
- 🌓 **主题切换**：日间/夜间模式
- 🔑 **盐值验证**：未登录时脚本不激活
- ⏳ **API退避机制**：请求失败时递增等待
- ⌨️ **快捷键**：`Ctrl+T` 快速开始/停止
- 📱 **双端适配**：PC + 移动端
- 💾 **位置记忆**：面板和按钮位置自动保存

### 相比旧版改进
- ✅ 冥想收功等待从 500ms 延长至 1500ms，避免状态不同步
- ✅ 同时支持 `clickStopMeditate()` 和 API 两种收功方式
- ✅ 更完善的错误处理和状态检测

## ✨ 天道试炼塔自动挑战助手

### 功能特性
- ⚔️ **自动挑战**：自动循环挑战试炼塔，支持设置目标层数
- 🎯 **智能选天赋**：暴击优先排序，同类型词条自动选数值最大，支持四种策略
- 💎 **灵石刷新**：自动使用灵石刷新天赋池，优先获取高品质天赋
- 📊 **天赋追踪**：实时显示天赋加成效果
- 🧬 **天赋组合记录**：记录当前轮次获得的所有天赋及稀有度统计
- 🧘 **冥想控制**：根据开关状态智能暂停/恢复冥想
- 🌓 **主题切换**：日间/夜间模式
- 🔑 **盐值验证**：未登录时脚本不激活
- ⏳ **API退避机制**：请求失败时递增等待（5~60秒）
- ⌨️ **快捷键**：`Ctrl+T` 快速开始/停止
- 📱 **双端适配**：PC端浮动面板 + 移动端抽屉式面板
- 💾 **位置记忆**：面板和按钮位置自动保存

### 天赋选择逻辑

#### 同类型词条选最大（v4.3.2 新增）
当可选天赋中出现多个同类型词条时，自动比较词条数值：
- 提取词条描述中的数值（如"攻击+15%" → 15）
- 选择数值最大的词条
- 数值相同时按稀有度选择（传说 > 稀有 > 普通）

#### 暴击未满时（<100%）
1. **特殊词条最优先**：不死 > 斩杀 ≈ 汲取 > 灵根共鸣
2. 暴击 > 攻击 > 生命 > 防御 > 灵力（同类型选最大）

#### 暴击已满时（≥100%）
1. 攻击 > 生命 > 防御 > 灵力（同类型选最大）
2. 无匹配则选默认第一个

### 天赋策略说明

| 策略 | 特点 |
|------|------|
| 综合平衡（暴击优先） | 优先暴击属性，兼顾各项数值 |
| 攻击优先 | 优先选择攻击类天赋 |
| 防御优先 | 优先选择防御/生命类天赋 |
| 传说品质优先 | 优先选择传说品质天赋 |

### 特殊词条识别
- ✨ **不死**：首次HP归零恢复20%HP
- ⚔️ **斩杀**：敌人HP<20%伤害翻倍
- 🌀 **天道汲取**：击杀回复30%HP+30%MP
- 🌿 **灵根共鸣**：灵根战斗特效强化
- ⚡ **天怒**：攻击+30%

## ⚒️ 自动炼制

### 功能特性

#### 炼造模块
- 🔥 **三模式支持**：炼丹、炼器、制符一键切换
- 📋 **智能配方选择**：自动加载可用配方，显示材料是否充足
- ⚡ **批量炼制**：自定义每次数量和循环次数，全自动生产
- 🛒 **材料补充**：材料不足时支持一键/自动静默购买材料
- 📊 **进度追踪**：实时进度条 + 状态提示
- 📝 **完整日志**：炼制过程详细记录，支持清空

#### 符篆模块
- 📿 **符篆批量使用**：自动从背包中识别并批量使用符篆
- 🎯 **类型筛选**：支持全部/战斗/隐匿三种符篆类型
- 🔄 **循环使用**：支持设置循环次数（0=无限）
- 🧘 **智能冥想处理**：自动检测并停止冥想状态
- ⚠️ **安全检测**：陨落/遭遇妖兽时自动暂停

### 炼制模式

| 模式 | 说明 | 默认间隔 |
|------|------|----------|
| 炼丹 | 自动炼制丹药 | 5秒 |
| 炼器 | 自动锻造装备 | 7秒 |
| 制符 | 自动制作符箓 | 3秒 |

### 符篆类型

| 类型 | 说明 |
|------|------|
| 全部 | 使用所有可用符篆 |
| 战斗 | 仅使用战斗类符篆 |
| 隐匿 | 仅使用隐匿类符篆 |

## 📥 安装方法

### 前提条件

#### 桌面端浏览器
安装浏览器扩展 **Tampermonkey** 或 **Violentmonkey**：
- [Chrome 版 Tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- [Firefox 版 Tampermonkey](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/)
- [Edge 版 Tampermonkey](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
- [Violentmonkey](https://violentmonkey.github.io/)

#### Via 浏览器（Android）
1. 下载安装 [Via 浏览器](https://viayoo.com/)
2. 打开 Via 浏览器，点击底部菜单 → **设置** → **脚本**
3. 开启 **脚本功能** 开关

### 安装脚本

#### 方式一：直接安装（推荐）

- [安装 自动试炼塔 [X]（Gitee）](https://raw.giteeusercontent.com/qiyes/ling-verse-script/raw/master/ling-trial-tower-assistant.js)
- [安装 天道试炼塔自动挑战助手（Gitee）](https://raw.giteeusercontent.com/qiyes/ling-verse-script/raw/master/ling-trial-tower-assistant.js)
- [安装 天道试炼塔自动挑战助手（GitHub）](https://raw.githubusercontent.com/ming-a1/LingVerse-Script/refs/heads/main/ling-trial-tower-assistant.js)
- [安装 自动炼制](https://gh-proxy.org/https://raw.githubusercontent.com/ming-a1/LingVerse-Script/main/ling-craft.js)

#### 方式二：手动安装
1. 打开 Tampermonkey/Violentmonkey 管理面板
2. 点击 **创建新脚本**
3. 复制对应脚本文件内容并粘贴
4. 保存即可

#### 方式三：Via 浏览器安装
1. 打开 Via 浏览器，进入 **设置** → **脚本**
2. 点击右上角 **+** 号 → **从链接导入**
3. 粘贴脚本直链地址
4. 点击 **确定** 导入
5. 确保脚本开关已开启

## 🎮 使用方法

### 自动试炼塔 [X] / 天道试炼塔自动挑战助手

1. 进入游戏后，打开 **天道试炼塔** 页面
2. 脚本会自动显示浮动按钮/面板
3. 配置策略和选项
4. 点击 **开始挑战** 或按 `Ctrl+T`

### 自动炼制 - 炼造

1. 点击右下角浮动按钮 ⚒️ 打开面板
2. 在 **功能选择** 中点击 **炼造**
3. 选择炼制模式 → 选择配方 → 配置参数
4. 点击 **开始炼制**

### 自动炼制 - 符篆

1. 打开面板后，在 **功能选择** 中点击 **符篆**
2. 选择符篆类型，配置参数
3. 点击 **开始使用符篆**

## 💡 常见问题

<details>
<summary><strong>Q: 脚本没有生效？</strong></summary>

- 确保已正确安装 Tampermonkey 扩展 / Via 脚本功能已开启
- 检查脚本是否处于启用状态
- 确认页面地址匹配 `ling.muge.info`
- **试炼塔助手需登录游戏后才能激活**
- 尝试刷新页面
</details>

<details>
<summary><strong>Q: 试炼塔 [X] 和旧版有什么区别？</strong></summary>

- [X] 版优化了冥想收功等待时间（500ms → 1500ms）
- 收功更稳定，减少因状态不同步导致的失败
- 推荐新用户使用 [X] 版
</details>

<details>
<summary><strong>Q: 符篆使用提示"需确认操作"？</strong></summary>

- 部分符篆需要手动确认，脚本会自动暂停
- 手动确认后可继续，或切换其他类型符篆
</details>

<details>
<summary><strong>Q: 炼制时提示材料不足？</strong></summary>

- 开启 **自动补材料** 开关，脚本会自动静默购买
- 也可手动点击 **[+ 补充]** 按钮预先购买
</details>
